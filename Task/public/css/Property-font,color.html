Font and Color

  1. Font

      2. Font Properties

    • font-family

      • serif

        • Serif fonts have small lines or strokes at the ends of their characters. They are often used in printed materials and are considered more traditional.

      • sans-serif

        • Sans-serif fonts do not have the small lines or strokes at the ends of their characters. They are often used in digital media and are considered more modern.

      • monospace

        • Monospace fonts have characters that take up the same amount of horizontal space. They are often used in coding environments and terminal applications.

    • font-size

      • px

        • Pixels (px) are a fixed unit of measurement that represents a specific number of pixels on the screen. They are commonly used for precise control over font size.

      • em

        • Em is a relative unit of measurement that is based on the font size of the parent element. 1em is equal to the font size of the parent element, so it allows for scalable and responsive typography.

      • rem

        • Rem is also a relative unit of measurement, but it is based on the font size of the root element (usually the element). 1rem is equal to the font size of the root element, making it easier to maintain consistent typography across different elements.

    • font-weight

      • normal

        • The normal font weight is the default weight for text. It is typically equivalent to a weight of 400.

      • bold

        • The bold font weight is used to make text appear thicker and more prominent. It is typically equivalent to a weight of 700.

      • lighter

        • The lighter font weight is used to make text appear thinner and less prominent. It is typically equivalent to a weight of 300.

      • medium

        • The medium font weight is used to make text appear at a moderate thickness. It is typically equivalent to a weight of 500.

    • Color

        • Color Properties

        • Named Colors

          • Named colors are predefined color names that can be used in CSS. Examples include "red", "blue", "green", etc.

        • Hexadecimal Colors

          • Hexadecimal colors are represented by a six-digit code that combines red, green, and blue (RGB) values. For example, #FF0000 represents red, #00FF00 represents green, and #0000FF represents blue.

        • RGB Colors

          • RGB colors are defined using the rgb() function, which takes three parameters representing the red, green, and blue values. For example, rgb(255, 0, 0) represents red, rgb(0, 255, 0) represents green, and rgb(0, 0, 255) represents blue.

        • HSL Colors

          • HSL colors are defined using the hsl() function, which takes three parameters representing the hue, saturation, and lightness values. For example, hsl(0, 100%, 50%) represents red, hsl(120, 100%, 50%) represents green, and hsl(240, 100%, 50%) represents blue.

        • HSLA Colors

          • HSLA colors are defined using the hsla() function, which takes four parameters representing the hue, saturation, lightness, and alpha values. For example, hsla(0, 100%, 50%, 0.5) represents red with 50% opacity, hsla(120, 100%, 50%, 0.5) represents green with 50% opacity, and hsla(240, 100%, 50%, 0.5) represents blue with 50% opacity.

        • Inherit

          • The inherit value causes an element to use the same color as its parent element.

        • Initial

          • The initial value resets the color to its initial value.

        • Unset

          • The unset value resets the color to its inherited value if it is inherited, otherwise it resets to its initial value.

        • Transparent

          • The transparent value makes the color fully transparent.

        • Revert

          • The revert value resets the color to the value established by the user agent stylesheet.
