Specificity

  • Inline styles
  • ID selectors
  • Class selectors
  • Element selectors

Specificity is a fundamental concept in CSS that determines which styles are applied to an element when there are conflicting rules. It is calculated based on the types of selectors used in the CSS rules. The more specific a selector is, the higher its specificity value, and it will take precedence over less specific selectors.

Specificity is calculated using a point system:

  • Inline styles (e.g., style="color: red;") have the highest specificity (1000 points).
  • ID selectors (e.g., #header) have a specificity of 100 points.
  • Class selectors (e.g., .container), attribute selectors (e.g., [type="text"]), and pseudo-classes (e.g., :hover) have a specificity of 10 points.
  • Element selectors (e.g., div, p) and pseudo-elements (e.g., ::before) have a specificity of 1 point.

When multiple CSS rules apply to the same element, the rule with the highest specificity will be applied. If two rules have the same specificity, the one that appears last in the CSS will take precedence.

Understanding specificity is crucial for writing effective CSS and ensuring that your styles are applied as intended. It helps you avoid unexpected results and allows you to manage the styling of your web pages more efficiently.
