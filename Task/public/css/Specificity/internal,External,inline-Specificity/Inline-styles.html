Internal, External, and Inline Specificity

Home page Inline styles Internal styles External styles

Specificity is calculated using a point system:

  • Inline styles (e.g., style="color: red;") have the highest specificity (1000 points).
  • Internal styles (e.g., styles defined within a tag in the HTML document) have a specificity of 100 points.
  • External styles (e.g., styles defined in an external CSS file) have a specificity of 10 points.
