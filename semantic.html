1. Header Tag

The header tag is used to define the header of a webpage or a section. It typically contains the website's logo, navigation menu, and other introductory content.

2. Nav Tag

The nav tag is used to define a section of navigation links. It helps users navigate through the website and find relevant content.

3. Article Tag

The article tag is used to define a self-contained piece of content that can be independently distributed or reused. It is often used for blog posts, news articles, or any other standalone content.

4. Section Tag

The section tag is used to define a thematic grouping of content. It can be used to divide a webpage into different sections based on topics or themes.

5. Aside Tag

The aside tag is used to define content that is tangentially related to the main content of the page. It is often used for sidebars, pull quotes, or any additional information that complements the main content.

6. Footer Tag

The footer tag is used to define the footer of a webpage or a section. It typically contains copyright information, contact details, and other relevant links.
